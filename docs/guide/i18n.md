# 多语言（i18n）

组件库内置**中文（zh-CN，默认）与英文（en-US）**两套语言包,覆盖聊天、审批、Markdown 渲染、文件面板、终端、会话列表等全部 UI 文案,并支持注册扩展语言。

## 快速使用

```vue
<CopilotProvider :config="{ locale: 'en' }">   <!-- 'zh' | 'en' | 'zh-CN' | 'en-US' -->
  <CopilotChat />
</CopilotProvider>
```

- `locale` 是响应式的:运行时修改 `config.locale` 即时切换全部文案,无需重建组件。
- 简写自动归一化:`'zh'` → `'zh-CN'`,`'en'` → `'en-US'`。

## 优先级(低 → 高)

1. **语言包**:内置 zh-CN / en-US,或 `registerLocale` 注册的扩展语言
2. **`config.labels` 用户覆盖**:向后兼容,始终最高优先(白标定制场景)

```ts
// labels 覆盖单条文案(不区分语言,始终生效)
{ locale: 'en', labels: { send: 'Go' } }
```

## 注册扩展语言

```ts
import { registerLocale, enUS } from '@od/agent-copilot-vue'

// 以英文包为底,覆盖为日语
registerLocale('ja-JP', { ...enUS, 'chat.send': '送信', 'chat.stop': '停止' })
// 使用
{ locale: 'ja-JP' }
```

缺失的 key 自动回退:当前语言包 → zh-CN → key 本身,注册部分翻译也不会出现空白文案。

## 组件内取翻译函数(自定义组件对齐库文案)

```ts
import { useI18n } from '@od/agent-copilot-vue'

const { t, locale } = useI18n()
t('chat.send')                    // "发送" / "Send"
t('md.expandAll', { n: 42 })      // 参数插值:"展开全部 42 行"
```

## 关键词条域

| 域 | 示例 key | 说明 |
| --- | --- | --- |
| `chat.*` | `chat.send` `chat.emptyTitle` | 聊天输入、消息操作、空态 |
| `hitl.*` | `hitl.approve` | 审批 / 中断确认 |
| `md.*` | `md.copy` `md.expandAll` | Markdown 渲染器按钮 |
| `files.*` | `files.filter` `files.lines` | 文件面板 |
| `session.*` | `session.search` `session.pin` | 会话列表 |
| `workspace.*` | `workspace.terminal` | 工作台面板页签 |
| `common.*` | `common.confirm` | 通用按钮 |
